# Ozon Bid Elasticity Optimizer

Локальное HTML-приложение для анализа фактической эластичности CPC по SKU в рекламных кампаниях Ozon.

## Запуск

Скачайте репозиторий и откройте `Ozon_Bid_Elasticity_Optimizer.html` двойным кликом. Сервер, npm и внешние CDN для работы приложения не нужны. Файлы `styles.css`, `elasticity.js`, `xlsx.js` и `app.js` должны лежать рядом с HTML.

## Что считает

- rolling day-to-day эластичности CPC → клики → корзины → общие заказанные единицы;
- spend-adjusted E заказов через first-difference модель `Δlog(orders+1) ~ Δlog(CPC) + Δlog(spend+1)`;
- качество данных текущего режима отдельно от идентифицируемости самой эластичности;
- причины неопределённости: CPC почти не исследован, мало заказов, confounding с расходом, широкая неопределённость, проблемы качества данных, неактивный текущий CPC;
- план следующего CPC-теста: целевой фактический CPC, минимальное число полных дней и объём событий.

Текущий неполный день исключается. Рекомендация использует актуальное окно (по умолчанию 21 полный день), а идентифицируемость E — всю загруженную историю.

## Проверка математики

```bash
node tests/elasticity-identifiability.test.js
```

Важно: рассчитанная длительность CPC-теста — план набора достаточного объёма событий, а не обещание формальной statistical power. Фактический CPC является наблюдаемой переменной; приложение не предполагает, что установленная ставка равна CPC.
